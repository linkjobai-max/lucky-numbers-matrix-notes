Lucky Numbers in a Matrix (LeetCode 1380): Row Minimums Meet Column Maximums

Given an m by n matrix of distinct numbers, a lucky number is the minimum element in its row and the maximum element in its column. Return all lucky numbers.

The direct approach

Compute every row minimum and every column maximum, then return the values that appear in both sets. Because the numbers are distinct, a value that is both a row minimum and a column maximum must be the same cell.

def luckyNumbers(matrix):
    row_min = {min(row) for row in matrix}
    col_max = {max(col) for col in zip(*matrix)}
    return list(row_min & col_max)

That is O(m*n) time and O(m+n) extra space.

The follow-up interviewers like

There is at most one lucky number. Suppose a at (r1, c1) and b at (r2, c2) were both lucky. Then a is at most matrix[r1][c2], which is at most b because b is its column maximum, and by the same argument b is at most a. Distinct values make that impossible. So you can return early: take the largest row minimum and the smallest column maximum, and they are lucky only if they are equal.

def luckyNumbers(matrix):
    a = max(min(row) for row in matrix)
    b = min(max(col) for col in zip(*matrix))
    return [a] if a == b else []

What to say out loud

  • Name the two sets first, then the intersection.
  • Offer the uniqueness proof only after the basic solution works.
  • Point out that zip(*matrix) transposes without extra loops.
